# AdminExpress: actividad de login responsive

Réplica del diseño de acceso de la actividad, realizada con HTML y CSS.

## Cómo abrirlo

Abre `index.html` en tu navegador. No requiere instalación ni dependencias.

## Diseño adaptable

- Escritorio: dos columnas con CSS Grid y panel azul de AdminExpress.
- Tabletas: dos columnas con espacios ajustados entre 601 y 900 px.
- Móviles: una columna, sin panel azul, hasta 600 px.

El CSS está incluido en el HTML. El formulario es una maqueta y no realiza autenticación.
